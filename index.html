JSON Imager

Sürüm 1.1.0

Windows masaüstü aracı · Açık kaynak · 2026

  • JSON belgelerini açıp içindeki tabloları kendiliğinden bulan; onları okunur metne, görsele ve grafiğe çeviren yerel bir araç. Hesap, sunucu ya da telemetri yok.
  • Farklı alanlara sahip kayıtları şema varyantlarına ayırıyor; tablo, şema ağacı ve grafikleri PNG, SVG, PDF, CSV, Markdown ve draw.io olarak dışa aktarıyor.
  • İsteğe bağlı bir ajan, belgenin yalnızca şemasını görerek yapı hakkındaki soruları yanıtlıyor; API anahtarları Windows DPAPI ile şifreli saklanıyor.
  • Python
  • JavaScript
  • HTML/CSS
  • WebView2
  • LLM entegrasyonu
